# SwordLab v2 (Fabric 1.21.11, Mojang mappings)

Client-side test modules for validating a server anti-cheat. Open the glass GUI with Right Shift.
Left-click a module = toggle, right-click (or arrow) = settings. Key settings: click the box, press a key
(Backspace clears). Slot keys use the number keys 1-9.

Sword:   Reach (3.0-4.5), Trigger Bot, Silent Aim Assist, Auto Jump Reset
Crystal: Anchor Macro, Auto Crystal, Auto Totem, Auto Inv Totem
Visuals: Aura, Health & Armor (HUD), Swing Animation, Viewmodel, Custom Sky (experimental)

Build on GitHub: upload these files to the repo ROOT, Actions tab -> build -> Run workflow, download swordlab-jar.
